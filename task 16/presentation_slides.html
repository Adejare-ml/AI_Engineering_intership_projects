AURA

Document Intelligence & Chat Portal

Enterprise AI Engineering Curriculum Capstone

Prepared by: Daniel Jare, Lead AI Engineer

The Problem

  • Unstructured Data Overload: Companies spend hours reading complex PDF/TXT documents.
  • API Latency: Standard LLM network calls take 2-4 seconds per response, violating SLAs.
  • Context Loss: Traditional chatbots cannot query files while retaining dialogue state.

The Solution: Aura Portal

  • Document Ingestion: Automatic parsing of PDF & TXT documents.
  • Automated Workflows: Multi-step summarization, takeaway, and recommendation extraction.
  • Contextual Chat: Stateful multi-turn conversation tracking referencing document data.
  • Redis Caching: Sub-5ms caching layer optimizing latency by 99.8%.

Technical Architecture

[ Spring Boot Gateway (8080) ]
              │
              ▼ (Proxy HTTP POST)
[ FastAPI Backend Service (8000) ]
        ├───▶ [ Redis Cache (6379) ] (Fast HIT)
        └───▶ [ Gemini 2.5 Flash API ] (Contextual MISS)

Performance Benchmarks

  • Cache MISS Latency: 1500ms - 2500ms (Gemini API network call)
  • Cache HIT Latency: < 5ms (Redis retrieval)
  • Latency Reduction: 99.8% speedup
  • Automated Coverage: FastAPI integration tests built on pytest.
