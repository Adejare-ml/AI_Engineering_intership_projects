# Task 5: Semantic Similarity Search

## About
This project implements a local semantic search engine using vector embeddings and the **FAISS** vector database. Rather than relying on simple keyword matching (which fails when different words are used to express the same concept), this system indexes document texts as dense vectors (embeddings) generated by a pre-trained **Sentence Transformers** model (`all-MiniLM-L6-v2`). The FAISS index processes exact cosine similarity searches to retrieve the top-k semantically relevant documents for any input query. A t-SNE visualization of the embedding space is also generated to show document clustering.

## Features
- **Sentence Encoder**: Generates 384-dimensional dense vectors using `sentence-transformers` (`all-MiniLM-L6-v2`).
- **Vector Database flat-index**: Built using FAISS `IndexFlatIP` for rapid, exact cosine similarity.
- **Multitopic Corpus**: Indexes 20 documents across four domains: AI/ML, vector databases, finance, and sports.
- **Visual Mapping**: High-dimensional embedding vectors are projected and plotted in 2D space using t-SNE.
- **Pinecone integration design**: Outlines the code structure for migrating queries to a cloud-managed Pinecone index.
