# Task 5: Semantic Similarity Search

Index 20 text documents as dense vectors. Query them by meaning. Return top-k matches.

No keyword overlap needed. The query "What optimization algorithm trains neural networks?" surfaces gradient
descent and backpropagation because the embedding captures meaning, not surface form.

---

## What it builds

| Component | Detail |
|-----------|--------|
| Encoder   | `sentence-transformers` — `all-MiniLM-L6-v2` (384-dim, L2-normalized) |
| Index     | FAISS `IndexFlatIP` — exact cosine similarity, no compression |
| Corpus    | 20 documents across 4 topics: AI/ML, vector databases, finance/fraud, sports |
| Output    | Top-k results with cosine scores + t-SNE embedding space plot |
| Bonus     | Pinecone integration pattern (commented, needs API key) |
