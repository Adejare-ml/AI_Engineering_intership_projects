# AI Engineering Internship Projects

Welcome to the central repository for the AI Engineering Internship tasks! This repository contains all of the code, solutions, and documentation for Tasks 1 through 16.

This repository strictly adheres to the submission guidelines:
- ✅ **GitHub repository only**: All code is hosted here.
- ✅ **Python Code Included**: Each task folder contains the relevant Python scripts (`.py`), modules, or complete backend/frontend solutions.
- ✅ **Data Files / Instructions**: Sample files are either included or generated dynamically via the scripts (e.g., sample PDFs, text files).
- ✅ **README for Every Task**: Every single task directory contains a detailed `README.md` that explains what the program does, how to run it, and lists the required libraries.
- ✅ **Runnable Repositories**: All tasks have been verified and are runnable locally with provided instructions.

## Repository Structure

The repository is organized into individual folders for each task. Please navigate into the specific task folder to view its code and instructions.

* **Task 1 to Task 7**: Core AI concepts, data processing, and initial integrations.
* **Task 8 to Task 11**: Evaluation systems, Memory/History implementation, LangGraph logic, and Tool Calling using Gemini API.
* **Task 12**: Real-time WebSocket Chatbot interface.
* **Task 13**: API Gateway implementation for traffic routing.
* **Task 14**: Caching optimizations with Redis for latency reduction.
* **Task 15**: Full Capstone Project integrating all elements into a unified, high-performance architecture.
* **Task 16**: Capstone Presentation Slides (HTML format).

## Getting Started

To explore or run any of the tasks:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Adejare-ml/AI_Engineering_intership_projects.git
   cd AI_Engineering_intership_projects
   ```

2. **Navigate to a Task**:
   ```bash
   cd "task 15" # Or whichever task you want to run
   ```

3. **Follow the Task's Specific README**:
   Each folder has a `README.md` containing specific prerequisites, environment variable setups (like setting `GEMINI_API_KEY`), and execution commands.

4. **Install Dependencies**:
   Each folder contains a `requirements.txt` file (or `pom.xml` / `package.json` where applicable) for its specific environment.
   ```bash
   pip install -r requirements.txt
   ```
